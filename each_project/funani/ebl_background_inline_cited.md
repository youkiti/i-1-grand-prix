# 船荷証券の電子化の法制化議論に至った背景

船荷証券（B/L）は紙の所持・引渡しで権利移転や第三者対抗を担保する仕組みで、商法も紙を前提としてきたため、電子化には「譲渡・支配」などの法的要件整理が不可欠だった（[法務省：法制審議会（船荷証券等の電子化）](https://www.moj.go.jp/shingi1/shingi03500044_00004.html)）。一方、紙B/Lは郵送遅延・紛失、偽造リスク、コロナ禍の業務停滞で国際物流のボトルネックとなり、貿易DXの要請が高まった（[内閣府：規制改革関連資料（貿易手続デジタル化・eBL）](https://www8.cao.go.jp/kisei-kaikaku/kisei/meeting/committee/220527/220527general_01.pdf)）。国際的には電子的移転可能記録のモデル法が整備され（[UNCITRAL：MLETR](https://uncitral.un.org/en/texts/ecommerce/modellaw/electronic_transferable_records)）、日本でも国際調和と取引安全確保の観点から法制化議論が進んだ。
