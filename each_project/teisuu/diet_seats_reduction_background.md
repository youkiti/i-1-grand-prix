# 議員定数削減が議論される背景

## 衆議院

衆院の定数削減議論は、まず「一票の格差」を是正する区割り・定数配分の見直し要請と結びついて進んだ（[最高裁大法廷 2017衆院選判決](https://www.courts.go.jp/assets/hanrei/hanrei-pdf-88202.pdf)）。その中で、差の縮小と「身を切る改革」を掲げた小選挙区の0増5減（[0増5減の成立経緯](https://www.jimin.jp/news/policy/129886.html)）や、定数10削減とアダムズ方式による自動的な再配分の導入（[区割り改定とアダムズ方式](https://www.sangiin.go.jp/japanese/annai/chousa/rippou_chousa/backnumber/2022pdf/20221216003-1.pdf)）が制度化。近年も、定数削減を期限付きで検討させる議員立法が提出されるなど（[衆法：衆議院議員の定数削減等](https://www.shugiin.go.jp/Internet/itdb_gian.nsf/html/gian/honbun/youkou/g21905011.htm)）、格差是正と政治改革・経費節減の論点が併走している。

## 参議院

参院の定数削減議論は、都道府県単位の選挙区に起因する「一票の格差」問題への対応が起点となった（[最高裁大法廷判決（参院・投票価値）](https://www.courts.go.jp/assets/hanrei/hanrei-pdf-89842.pdf)）。是正策として2015年に10増10減と4県2合区が導入され（[参院調査：合区導入の経緯](https://www.sangiin.go.jp/japanese/annai/chousa/rippou_chousa/backnumber/2015pdf/20150904003s.pdf)）、その後2018年には較差縮小のための定数増や比例の特定枠が盛り込まれ、賛否を呼んだ（[参院調査：2018年改正（定数増・特定枠）](https://www.sangiin.go.jp/japanese/annai/chousa/rippou_chousa/backnumber/2018pdf/20180907003.pdf)）。改革協議会でも、身分保障・役割・選挙制度を含めた「定数の在り方」が継続審議されている（[参議院改革協議会報告書](https://www.sangiin.go.jp/japanese/kon_kokkaijyoho/sankaikyou/r3/pdf/r4kyougikai_houkokus.pdf)）。
