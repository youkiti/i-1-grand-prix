# AI基本計画の策定に関わる経緯

生成AIの急速普及で国際的にガバナンス整備が進み、日本もG7議長国として広島AIプロセスで国際指針・行動規範を取りまとめた（[外務省：広島AIプロセス首脳声明](https://www.mofa.go.jp/mofaj/ecm/ec/page5_000483.html)）。こうした流れを受け、政府はAIの研究開発・活用を促進しつつリスク対応も図る[AI法](https://www8.cao.go.jp/cstp/ai/ai_act/ai_act.html)を成立・全面施行し（[内閣府：AI法 全面施行](https://www.cao.go.jp/press/new_wave/20251003.html)）、同法に基づく基本計画の策定を首相が指示した（[首相官邸：AI戦略会議 2025-06-02](https://www.kantei.go.jp/jp/103/actions/202506/02ai.html)）。その後、[人工知能戦略本部](https://www.kantei.go.jp/jp/103/actions/202509/12jinkoutchinou.html)で検討を開始し、[人工知能基本計画（案）](https://www8.cao.go.jp/cstp/ai/ai_plan/ai_plan.html)の公表へ至った。
