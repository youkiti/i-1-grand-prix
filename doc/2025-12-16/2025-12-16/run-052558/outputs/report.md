# 用語解説（Glossary of Terms）

| 用語 | 解説（高校生にもわかる説明） |
|------|------------------------------|
| 人工知能基本計画 | AI（人工知能）技術の研究や活用を、国としてどのように進めていくかを定めた計画のこと。AI関連の法律に基づき、政府が作成します。 |
| AI戦略本部 | 日本のAI政策の司令塔となる組織のこと。内閣総理大臣をトップとし、すべての閣僚が参加して、省庁間の連携や迅速な意思決定を行います。 |
| LLM（大規模言語モデル） | ChatGPTなどの基盤となる、大量のテキストデータを学習したAIモデルのこと。言葉の意味を理解し、自然な文章を作成することができます。 |
| AGI / ASI | AGI（汎用人工知能）は人間のようにあらゆる知的作業ができるAI、ASI（人工超知能）は人間の知能を遥かに超えたAIのことです。 |
| ソブリンAI（国産AI） | 他国の技術に依存せず、自国のデータセンターや技術基盤で開発・運用されるAIのこと。経済安全保障や文化的な独立性を保つために重要視されています。 |
| GPU | 元々は画像処理用の半導体チップでしたが、現在ではAIの学習や計算処理に不可欠な部品となっています。世界的に奪い合いが起きています。 |
| デジタル赤字 | デジタルサービス（クラウド、ソフトウェア、SNSなど）の利用料として海外企業に支払う金額が、日本企業が海外から受け取る金額を上回っている状態のこと。 |
| ソフトロー / ハードロー | 「ハードロー」は法律による罰則付きの強制的な規制。「ソフトロー」はガイドラインや自主規制など、柔軟に対応できる緩やかなルールのことです。 |
| DFFT | 「信頼性のある自由なデータ流通」の略。プライバシーやセキュリティを確保しながら、国境を越えてデータを自由にやり取りできるようにする国際的な考え方です。 |
| 質問主意書 | 国会議員が内閣（政府）に対して、文書で質問を行う制度のこと。内閣は原則7日以内に文書で回答しなければなりません。 |

# 1. パブリックコメントによる仮説の検証

審議会資料で提示された方針に対し、パブリックコメントにおいてその方向性を支持、あるいはその重要性を再確認する意見が見られました。

*   **国産AI開発と経済安全保障の重要性**
    審議会ではデジタル赤字の解消や経済安全保障の観点から、国内でのAI開発力強化の方針が示されました。パブリックコメントでも、他国への依存による地政学リスクや「知能主権」の喪失を懸念し、国産AI（ソブリンAI）の開発を必須とする意見が確認されました。
    > 「海外のサービスを活用するだけではデジタル赤字がますます拡大します。ＡＩを日本の中で開発するための開発力の強化についても、政策として取り組んでいくことが重要です。」 [出典: kokkai_001]
    > 「国産であるというのは国のデータを利活用できるAIを持つ事でデータと知能の主権を国が維持できる事を目指すもので、今後多くの国は知能主権がない状態にされます。つまり自国でAIを主体的に開発運用出来ない国はデータ植民地や知能植民地に成り下がる可能性が高いでしょう。」 [パブコメ: fd3a1862-67e9-4450-aebb-31e184beffa0]

*   **AI戦略本部の司令塔機能への期待**
    審議会では、AI戦略本部による府省横断的な対応と迅速な意思決定の重要性が議論されました。パブリックコメントでも、国が強力なリーダーシップを発揮し、インフラ運営などを管理すべきであるという意見があり、国の関与強化という方向性が支持されています。
    > 「ＡＩ戦略本部の事務局である内閣府が、ＡＩに関する情報収集や調査、情報提供等を実施することとなっております。（中略）政府全体として一層迅速にこうした課題への対応をしっかり図っていくことが可能になるというふうに考えております。」 [出典: kokkai_001]
    > 「個人的には国が運営すべきだと思います。それこそが国が科学技術で食っていく、と宣言するのに等しいと思うからです。インフラ事業というのはハコモノだけではありません。国が管理することで国への高度人材の流入や雇用問題の解決などこのインフラはハコモノと安全保障を兼ねたものだと思います。」 [パブコメ: 8f591a15-b95b-4675-8db7-ea55b3d329dc]

*   **人材育成と待遇改善の必要性**
    審議会では、AI人材の育成・確保やリスキリングの重要性が指摘されました。パブリックコメントでも、研究者や技術者が不足している現状への懸念が示され、予算不足や待遇面での課題意識が共通しています。
    > 「ＡＩの研究開発、活用の進展や、ＡＩによる新たな産業の創出に伴い、ＡＩエンジニアを始めとするＡＩ関連人材のニーズは高まっている状況にあると認識をしております。」 [出典: kokkai_001]
    > 「絶望的に予算が足りない、技術者も足りない、というのは気になります」 [パブコメ: 87ca5ab5-43ba-4bdf-b57e-7098373b4276]

# 2. パブリックコメントによる反対・懸念の顕在化

審議会での議論に対し、パブリックコメントでは規模感、スピード感、および具体的な手段において、政府方針との乖離や強い懸念が示されています。

*   **投資規模と財源に対する認識のギャップ**
    審議会では予算規模について具体的な数値目標の設定は慎重な姿勢（適時適切に議論）が示されましたが、パブリックコメントでは、現状の投資額が「1桁か2桁少ない」と指摘されています。米中に対抗するためには国家予算レベル（100兆円規模、国債発行等）の資金投入が必要であるとの意見が複数見られます。
    > 「ＡＩの民間投資などの指標については、（中略）具体的な目標や指標の設定については適時適切に議論する必要があると考えております。」 [出典: kokkai_001]
    > 「50点。方向性は同意でし、期待するが、言ったように実現には、近年の技術に対する投資に比べ、必要予算が2、3桁以上必要。米国の関連企業同士の投資額を見たら…。という事でこの点数にします。」 [パブコメ: fce23154-a226-46a5-a705-a5cd5caa1687]
    > 「AIインフラの整備には、100兆〜200兆円規模の投資が必要になる可能性がある。この財源は、国債発行（＝通貨発行）によって十分に賄える。」 [パブコメ: d6600d41-1d70-49b1-be79-9c8125087e54]

*   **計算資源（GPU）と電力確保への具体策の欠如**
    審議会では「ワット・ビット連携」や一般的なインフラ整備に留まっていますが、パブリックコメントではGPUの圧倒的な不足と、それに伴う電力需要への対応（特に原子力発電の再稼働や新設）について、より踏み込んだ具体的な対策を求める声が強くあがっています。
    > 「具体的な施策の方につきましては、これも、研究開発の推進ですとか、今日御議論いただいているような、データの整備、共用ですとか、あるいはデータセンターの整備とか共用とか、そういったことを進めていく」 [出典: kokkai_001]
    > 「計算機資源の確保が全く足りていない。（中略）信頼できるAIを作るということは、フロンティアモデルを作るということだ。ならば、圧倒的にGPUが足りていない。問題に正面から向き合っていない。」 [パブコメ: 73a4edc3-00a6-4b8c-88cc-97ff55ce3099]
    > 「原子力発電の再稼働と地域の誘致策と思います（データセンターが嫌悪施設に思われてるので）」 [パブコメ: 5e18d195-a043-49d1-b6c1-a8d439c5aaf6]

*   **開発スピードと「慎重さ」への批判**
    審議会では「イノベーション促進とリスク対応の両立」が理念として掲げられていますが、パブリックコメントの一部には、倫理や慎重さを優先することで開発スピードが遅れ、国際競争に敗北することへの懸念が示されています。「爆速で開発」や「倫理は諦めてスピード重視」といった極端な意見も見られます。
    > 「イノベーションの促進とリスク対応の両立ということはしっかり書いていかないといけないと思いますし」 [出典: kokkai_001]
    > 「ちがう。もう倫理は諦めて、とにかくスピード重視で開発支援する は良いと思っている。これ以外にない。」 [パブコメ: 9b81db0a-69da-44b8-90e2-5aa5bfc0142a]
    > 「外国と比べ、ゆっくりしたスピードのわりに一歩が慎重すぎて、発電やスクレイピングなど、マネーゲームに置いて行かれる日本が見える」 [パブコメ: 54c38007-5307-445f-9c47-8e7ff04ae9d1]

# 3. 新たなインサイト・論点

審議会資料には明確に現れていなかった視点として、以下の論点がパブリックコメント分析から浮上しました。

*   **災害時におけるAIシステムの強靭性（オフラインAI）**
    電力供給や通信が途絶した場合でも機能する「独立型AI」や「オフライン動作」の必要性が指摘されています。災害大国である日本の事情を考慮した、独自のレジリエンス（強靭性）要件と言えます。
    > 「オフラインでも動作する独立型のAIシステム 従来の人力による救助と併用する体制」 [パブコメ: 74df0f67-84b9-4ac0-9602-e9bec2afdc19]

*   **物理的インフラの防衛と地下化**
    データセンターや電力設備をテロ攻撃や有事から守るため、地下施設の建造やドローン対策といった物理的な防御策を講じるべきという意見があります。サイバーセキュリティだけでなく、物理セキュリティを安全保障の一部として捉える視点です。
    > 「テロリストは電源を狙うでしょうから、有事の際は、電源設備のドローン対策はマストです。地下施設を建造するべきです。地下なら原発で何かあっても遮断できます。」 [パブコメ: 08dde19c-e725-43dd-8c03-0ec9bc5a0b2d]

*   **「人間中心」の定義としての物理的制御権**
    「人間中心のAI」という理念に対し、AIが暴走した際に物理的に停止できるよう、GPUや電力の管理権限を人間が保持することをその具体的定義とすべきという意見があります。抽象的な倫理規定ではなく、物理的な制御を重視する視点です。
    > 「人類としてのGPUや電力管理です。AIを悪用しようとしても、推論するためのGPUや電力が無ければ、何もできません。だからこそAIにGPUや電力関連を扱う権限は人間が保持しなければならないと考えています」 [パブコメ: 292c0dfe-473e-473f-9b26-57d6600cda5d]

# 5. 今後の対応方針案（国会アクションカード形式）

## 5.1 まとめ

パブリックコメント分析からは、政府案の「国産AI開発」という方向性は支持されているものの、それを実現するための**「圧倒的な資金不足」**と**「電力・インフラの具体策欠如」**に対する強い危機感が浮き彫りになりました。国会アクションとしては、単なる理念法や計画策定にとどまらず、**「財政措置（予算）」**と**「エネルギー政策」**、そして**「物理的な安全保障」**をセットで動かす必要があります。

推奨コンボ: **質問主意書**（現状の不足をデータで質す） → **委員会質疑**（予算とエネルギーのコミットを引き出す） → **修正案/附帯決議**（基本計画への具体的リソース担保の明記）

## 5.2 論点マップ

| 論点 | 何が問題か | だれに影響か | どのレイヤーで動くか |
| :--- | :--- | :--- | :--- |
| **投資規模** | 米中に比べ予算が数桁少なく、国産開発が画餅になる恐れ | 国内AI産業、研究者、将来の国力 | **予算** / 法律（財政措置規定） |
| **電力・インフラ** | AIに必要な膨大な電力（原発含む）やGPU確保の計画が曖昧 | データセンター事業者、電力消費者、産業界全体 | **政省令**（エネルギー基本計画） / 予算 |
| **安全保障** | データセンターの物理防衛や「知能主権」の観点が希薄 | 国民全体（有事のインフラ維持） | **監督強化** / 法律（経済安保推進法） |
| **災害対応** | 通信途絶時のAI利用（オフライン化）が想定されていない | 被災者、自治体現場 | **政省令**（防災計画） / 研究開発予算 |

## 5.3 推奨アクション（カード別）

### カード3: 質問主意書（政府に対する公式質問）

*   **ねらい**: 委員会質疑の前に、政府の現状認識（特に予算規模と電力需要の見積もり）における国際比較とのギャップを文書で確定させ、逃げ道を塞ぐ。
*   **使うべき論点**: 投資規模、計算資源（GPU）の確保量、電力供給の具体的見通し。
*   **具体アクション**:
    *   主要国（米中英仏等）のAI関連公的投資額と日本の比較データを問う。
    *   政府が掲げる「国産AI開発」に必要な計算資源量と電力需要の試算根拠を問う。
    *   有事や災害時におけるデータセンターの物理的防護措置の現状を問う。
*   **期待アウトカム**: 政府が「現状の予算では不足していること」や「電力確保の具体的計画が未定であること」を認めざるを得ない答弁を引き出し、次期予算編成やエネルギー政策見直しの根拠とする。
*   **リスクと代替策**: 「現在検討中」というゼロ回答が返ってくる可能性があるため、過去の答弁や海外の公開データと比較して矛盾を突く質問構成にする。

### カード2: 国会の各種委員会での質疑・発言

*   **ねらい**: 経済産業委員会や内閣委員会において、パブコメで示された「国民の危機感」を直接大臣にぶつけ、基本計画への「覚悟」を迫る。
*   **使うべき論点**: 投資規模（100兆円規模の要望）、エネルギー政策（原発再稼働や新設の是非）、災害時のレジリエンス。
*   **具体アクション**:
    *   パブコメの「投資額が2桁足りない」という意見を引用し、財務省・経産省に見解を求める。
    *   「知能主権」や「データ植民地」という言葉を使い、AI開発を単なる産業振興ではなく「国防・安全保障」の問題として定義し直すよう迫る。
    *   防災担当大臣に対し、通信断絶下の「オフラインAI」の研究開発支援を提案する。
*   **期待アウトカム**: 基本計画の改定や、次年度予算におけるAI関連費枠の大幅な増額、あるいはエネルギー基本計画へのAI需要の明記。
*   **リスクと代替策**: 財源論で「増税」と結びつけられると世論が反発する可能性があるため、「建設国債」や「予備費」など、国民負担増に直結しない財源論を提示する。

### カード5: 提出されている法律案への修正案の提出（または附帯決議）

*   **ねらい**: 法律や基本計画の承認にあたり、政府に対してより踏み込んだ措置を義務付ける。
*   **使うべき論点**: 財政上の措置、定期的な見直し（PDCA）、安全保障の観点。
*   **具体アクション**:
    *   AI推進法の附則や基本計画の承認決議において、「政府は、AI開発に必要な計算資源及び電力を確保するため、必要な財政上の措置及び制度的な対応を速やかに講ずるものとする」といった文言を追加する。
    *   「災害時等の非常事態においても機能するAIシステムの在り方について検討すること」を附帯決議に盛り込む。
*   **期待アウトカム**: 法律や国会決議という形で政府を拘束し、計画倒れを防ぐ。
*   **リスクと代替策**: 法案修正はハードルが高いため、与野党合意が形成しやすい「附帯決議」での対応を現実的な着地点とする。
