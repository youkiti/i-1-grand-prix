# 用語解説（Glossary of Terms）

| 用語 | 解説（高校生にもわかる説明） |
|------|------------------------------|
| **人工知能基本計画** | 政府がAI（人工知能）をどのように開発し、社会で使っていくかを定めた全体的なスケジュールのこと。法律に基づいて作られます。 |
| **広島AIプロセス** | 2023年のG7広島サミットで日本が主導してまとめた、安全で信頼できるAIを作るための国際的なルールの枠組みのこと。 |
| **LLM（大規模言語モデル）** | 大量のテキストデータを学習して、人間のように自然な文章を作ったり質問に答えたりできるAIの技術。ChatGPTなどがこれに当たります。 |
| **ディープフェイク** | AIを使って、実在する人の顔や声を本物そっくりに合成した偽の動画や音声のこと。詐欺や偽情報の拡散に使われるリスクがあります。 |
| **ソフトロー** | 法律のような強制力のあるルール（ハードロー）ではなく、ガイドラインや自主規制など、柔軟に対応できる緩やかなルールのこと。 |
| **DFFT（信頼性のある自由なデータ流通）** | プライバシーやセキュリティを守りながら、国境を越えてデータを自由にやり取りできるようにしようという考え方。 |
| **リスキリング** | 新しい技術や仕事に対応するために、社会人が新しいスキルや知識を学び直すこと。 |
| **アジャイルガバナンス** | 技術の進化が速い分野において、一度決めたルールを固定せず、状況を見ながら柔軟かつ素早くルールを見直していく仕組みのこと。 |

# 1. パブリックコメントによる仮説の検証

審議会での議論とパブリックコメントの方向性が一致し、政府の方針が支持されている論点です。

**1. 国内AI開発能力の強化と計算資源への投資**
デジタル赤字の解消と経済安全保障の観点から、海外サービスへの依存を脱却し、国内でAIを開発する能力（計算資源や人材）を強化すべきという点で意見が一致しています。

> 「海外のサービスを活用するだけではデジタル赤字がますます拡大します。ＡＩを日本の中で開発するための開発力の強化についても、政策として取り組んでいくことが重要です。」 [出典: kokkai_003]
> 「国内のAI産業が海外プラットフォーマーの下請けにならないよう、国産LLMの開発支援と計算資源（GPU等）の確保に国費を重点的に投じるべきである。」 [パブコメ: fb5df556-0ebb-4913-a3c1-5a8e50adaf0c]

**2. 全世代を通じたAIリテラシー教育の必要性**
学校教育だけでなく、社会人や高齢者を含めたリテラシー教育の重要性について、審議会とパブリックコメントの双方が強く求めています。

> 「学校、民間事業者、公的機関などがしっかり連携して利用者のリテラシー教育を進めていくことが、委員の御指摘のとおり、極めて重要だというふうに考えております。」 [出典: kokkai_004]
> 「子供たちがAIを安全に使うための教育はもちろん、高齢者がAI詐欺の被害に遭わないためのリカレント教育や啓発活動を基本計画に明記してほしい。」 [パブコメ: af5436eb-3767-4701-8571-14fb857bbaae]

**3. AI戦略本部の司令塔機能への期待**
縦割り行政を排し、内閣総理大臣をトップとする強力な司令塔機能を求める点でも整合しています。

> 「ＡＩ戦略本部を設置するなど、ＡＩ政策の司令塔機能を強化することとなっております。」 [出典: kokkai_001]
> 「省庁間でたらい回しにされることなく、AI戦略本部が責任を持って迅速な意思決定を行える体制を構築してください。」 [パブコメ: 9d112350-0d9e-4cee-b696-4dc2701aa080]

# 2. パブリックコメントによる反対・懸念の顕在化

審議会の方針に対し、パブリックコメントで懸念や異論が多く寄せられた論点です。

**1. 著作権侵害への対応（ガイドライン vs 法規制）**
審議会では「既存の法令とガイドライン（ソフトロー）」での対応を基本としていますが、パブリックコメントではクリエイター層を中心に、より強力な「法規制（ハードロー）」や「学習拒否権（オプトアウト）の実効性確保」を求める声が多数見られます。

> 「法、技術、契約、この三つの手段の適切な組合せにより、ＡＩに関する懸念や知的財産権の侵害リスクに対応していくことが必要である」 [出典: kokkai_003]
> 「ガイドラインや当事者間の努力に任せるのではなく、無断学習を原則禁止とする法改正や、学習データセットの開示を義務付ける法的拘束力のある規制が必要です。」 [パブコメ: 1b35b52d-f4b0-46aa-9a7f-3c456dc243be]

**2. ディープフェイク対策の実効性**
政府は「既存法令（名誉毀損、児童ポルノ禁止法等）の活用」を優先する姿勢ですが、パブリックコメントでは、生成AI特有の拡散力や被害の深刻さを踏まえ、生成AIの悪用自体を直接取り締まる新法を求める意見が散見されます。

> 「生成ＡＩを悪用したディープフェイクポルノを含めた新たな課題への対応につきましては、まずは個別の事案ごとに、刑法やいわゆる児童ポルノ禁止法等の既存の法令にのっとり適正に対処されていくべき」 [出典: kokkai_001]
> 「既存の法律では、作成された時点で被害を防ぐことが難しく、拡散後の削除も困難です。ディープフェイクの作成・公開自体を規制する新しい法律を制定すべきです。」 [パブコメ: a871aed4-ae38-43cd-bea6-954a614e13dd]

**3. 「人間中心」原則の法的担保**
審議会では「基本計画の冒頭に記載することで担保する」としていますが、パブリックコメントでは、法律の条文（目的規定など）に明記しなければ、経済優先で人権が軽視される懸念があるとの指摘があります。

> 「基本計画の冒頭に記載されることで、法案に直接書き込まずとも、人間中心のＡＩ原則に基づき、各施策が行われることを担保できると考えております。」 [出典: kokkai_006]
> 「基本計画は行政の方針に過ぎず、政権が変われば変更可能です。個人の尊厳や人権を守る『人間中心』の原則は、法律の条文にしっかりと明記すべきです。」 [パブコメ: 635a9ac6-c444-4722-8ea1-9d6c5e418ac9]

# 3. 新たなインサイト・論点

審議会資料では主要な論点となっていなかったものの、パブリックコメントによって浮き彫りになった視点です。

**1. AI開発に伴う環境負荷への配慮**
審議会では計算資源の確保が議論されましたが、パブリックコメントでは、データセンターの電力消費増大に伴う環境負荷（CO2排出量）への懸念と、省エネ技術開発への投資要請が指摘されています。

> 「AI開発競争による電力消費の爆発的な増加を懸念します。基本計画には、グリーンAIの開発やデータセンターの省エネ化に向けた具体的な数値目標と環境配慮義務を盛り込むべきです。」 [パブコメ: 4b2a79fc-e984-4e2c-8e42-9df2eaeaed54]

**2. 声優・実演家の権利保護（ボイス・ライツ）**
著作権全般の議論に加え、特に「声」の無断利用（AIカバー等）に対する人格権的な保護や、実演家の権利確立を求める具体的な要望が寄せられています。

> 「画像生成だけでなく、声の無断合成に対する法的な保護が曖昧です。声優や歌手の『声』そのものを守る権利（パブリシティ権の明文化など）を検討してください。」 [パブコメ: a5593da2-4dc6-4323-b97f-37ec78c1a52d]

# 4. 対立軸に対するパブリックコメントの反応

### 生成AIによるリスク（ディープフェイク等）への対応原則（審議会: 既存法令の活用 ←→ 新法・個別規制）

| パブコメの立場 | 代表的な意見（verbatim_quote から引用） | 出典 |
| :--- | :--- | :--- |
| **新法・個別規制支持** | 「既存法での対応には限界があり、AIによる権利侵害に特化した迅速な差止請求や罰則を含む新法が必要です。」 | `[パブコメ: b9ef9a62-ec1c-48e2-b81b-4aaa5ef3cd77]` |
| **既存法令活用支持** | 「過度な規制は技術革新を阻害するため、まずは現行法の適用を徹底し、ガイドラインで対応すべきです。」 | `[パブコメ: 2830cd35-ddaa-4617-a968-dd9bb404edef]` |

- **審議会での状況**: 継続検討（政府は既存法令活用優先だが、委員からは新法の必要性指摘あり）
- **パブコメの傾向**: 被害防止の観点から「新法・個別規制」を求める声が優勢である一方、事業者からはイノベーション阻害を懸念する声もあり、意見が割れている。
- **合意形成への示唆**: 直ちには新法制定に至らずとも、基本計画において「法制度のあり方の継続的な検討」と「被害者救済の簡易迅速化」を明記することが妥協点となる可能性があります。

### リスク対応：著作権保護と透明性確保の強化（審議会: 現行法・指針で対応 ←→ 法改正による規制強化）

| パブコメの立場 | 代表的な意見（verbatim_quote から引用） | 出典 |
| :--- | :--- | :--- |
| **法改正強化支持** | 「学習データの透明性確保は努力義務ではなく、開示を義務化しなければ実効性がありません。」 | `[パブコメ: e770a6f3-a85d-45b5-825c-35932256fbc7]` |
| **現行法・指針対応支持** | 「一律の開示義務や規制強化は、日本でのAI開発を停滞させるため、柔軟なガイドライン対応が望ましい。」 | `[パブコメ: ed4e8371-f6c3-4d71-8913-17a14687d558]` |

- **審議会での状況**: 継続検討（大臣は指針に透明性確保を盛り込む方針だが、法改正は明言せず）
- **パブコメの傾向**: クリエイター層からの「法改正・規制強化」を求める声が圧倒的に多く、現状の政府方針（指針対応）に対する不満が顕在化している。
- **合意形成への示唆**: 指針（ガイドライン）の実効性を高めるため、遵守しない事業者への行政指導や公表措置など、ソフトローの中でも強制力に近い運用を検討する必要があります。

# 5. 今後の対応方針案（国会アクションカード形式）

## 5.1 まとめ
パブリックコメントでは、**「著作権・クリエイター保護」**と**「人権尊重の法的担保」**に関して、政府案（ソフトロー中心）よりも踏み込んだ対応を求める声が強く出ています。これらを受け止めつつ、イノベーションを阻害しない現実的な着地点を見出すため、**国会での質疑を通じて政府の言質を引き出し、附帯決議や基本計画への具体的記載につなげる**アプローチを推奨します。

**推奨コンボ:** カード2（委員会質疑）→ カード5（修正案・附帯決議）→ カード4（陳情採択）

## 5.2 論点マップ

| 論点 | 何が問題か | だれに影響か | どのレイヤーで動くか |
| :--- | :--- | :--- | :--- |
| **著作権・透明性** | 指針（ガイドライン）だけでは学習データの開示が進まない懸念 | クリエイター、AI事業者 | 政省令（指針策定）、監督強化 |
| **人間中心の原則** | 法律の条文にないため、将来的に経済優先で軽視されるリスク | 国民全体 | 法律（修正案）、基本計画 |
| **ディープフェイク** | 既存法では拡散のスピードや作成行為自体に対応しきれない | 被害者、著名人 | 法律（新規立法検討） |

## 5.3 推奨アクション（カード別）

### カード2: 国会の各種委員会での質疑・発言

- **ねらい**: 政府方針（指針対応）の具体性と実効性を問い質し、議事録に残すことで、行政の運用を縛る。
- **使うべき論点**: 著作権保護の透明性確保、ディープフェイクへの対処スピード、人間中心原則の担保。
- **具体アクション**: 内閣委員会において、「指針に従わない事業者に対して、政府は具体的にどのような措置を講じるのか」「基本計画に記載するだけでなく、法改正の検討期限を設けるべきではないか」と質問する。
- **期待アウトカム**: 大臣から「指針の実効性を確保するため、状況に応じて法改正も排除しない」といった答弁を引き出し、将来の規制強化への布石を打つ。
- **リスクと代替策**: ゼロ回答（検討します）で終わるリスクがあるため、具体的な事例（海外の規制事例や被害事例）を挙げて迫る。

### カード5: 提出されている法律案への修正案の提出（または附帯決議）

- **ねらい**: パブコメで懸念が強かった「人間中心の原則」や「権利保護」について、法案修正または附帯決議によって政府の宿題とする。
- **使うべき論点**: 人間中心の原則の明記、著作権者等の権利保護への配慮。
- **具体アクション**: 法案の附則や附帯決議案に、「政府は、AI技術の進展に応じ、個人の権利利益の保護のために必要な法制度の在り方について検討を加え、その結果に基づいて必要な措置を講ずる」旨を盛り込むよう与野党協議を行う。
- **期待アウトカム**: 法律成立後も、政府が継続的に規制の強化や見直しを行わざるを得ない法的根拠を作る。
- **リスクと代替策**: 与党の賛成が得られない場合、否決される。その場合は、附帯決議（全会一致を目指すもの）に落とし込む交渉を行う。

## 5.4 追加で確認したい情報

1.  **パブリックコメントの属性内訳**: 意見提出者が「個人（クリエイター等）」か「事業者」か「団体」かの比率（対立構造の深さを測るため）。
2.  **海外（EU AI法等）との整合性に関する詳細な意見**: 日本の規制が緩すぎることで、逆に日本企業が海外展開しにくくなるという指摘の有無。
