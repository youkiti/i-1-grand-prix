    1. **AIガバナンスと法制度改革**: 広島AIプロセスを主導し国際相互運用性を確保しつつ、国内ではAI法に基づくAI指針を整備。規制手法は、技術変化に柔軟に対応できるゴールベースのソフトローを中心としつつ、高リスクAIのオペレーターには厳格責任の適用や、AIエージェントの限定的な法人格付与の是非を検討するなど、民事責任制度の抜本的な見直しを推進する。AIセーフティ・インスティテュート（AISI）を抜本的に強化し、AIモデルの安全性・適正性評価機能の構築、国際標準化活動への戦略的関与を強化する。国民の権利利益を侵害する重大インシデント発生時の政府による調査権限の法定化が求められている。
    2. **AI開発力の戦略的強化**: 国家主権と安全保障の観点から、フィジカルAIやAI for Scienceを日本の勝ち筋として特定。富岳NEXT、AIデータセンター、高性能AI半導体を含む計算資源の戦略的増強と、高品質な日本語学習データの整備・提供を加速する。生成AI基盤開発への大規模投資（2023年度補正予算で400億円など）が国家戦略として推進されている。
    3. **AI人材育成と雇用対策**: 年間25万人を目標とする教育プログラム認定制度の普及（全学開講、PBL、ELSI教育の組み込み）を推進するとともに、AIによる雇用影響を分析し、労働者向けのリスキリング支援や「アドバンスト・エッセンシャルワーカー」の育成を含む包括的な対策を講じる。
    4. **公共分野でのAI利活用**: 政府機関におけるAI統括責任者（CAIO）の設置、省庁横断の生成AI利用プラットフォーム「ガバメントAI」の本格的構築を加速する。医療・介護、産業保安、金融（与信審査）、農業といった重要分野でのAI活用推進と、データ連携基盤の整備、およびAI利用を前提とした既存規制（割賦販売法、産業保安規制など）の迅速な見直しを推進する。
